# 🎮 Splatoon Role Bot (Serverless Edition)

スプラトゥーン向け Discord ロール管理Bot。  
Vercel サーバーレス関数（Interactions Webhook）として動作し、常時稼働サーバー不要で24時間運用が可能です。メンバーがボタンを押すだけでロール（役職）を付け外しでき、スプラトゥーン3のスケジュール情報を自動＆手動で確認できます。

## 機能

### ロール管理
- **武器種ロール**: シューター、ローラー、チャージャー、スロッシャー、スピナー、マニューバー、シェルター、ブラスター、フデ、ストリンガー、ワイパー（11種）
- **モードロール**: バンカラマッチ、Xマッチ、サーモンラン（3種）
- **ウデマエ(ランク)ロール**: X、S、A、B、C（5種）
- **トグル形式**: ボタンを押すとロール付与、もう一度押すとロール解除
- **シームレストグル**: ボタン操作時にメッセージ通知を行わず、スピーディーに切り替え
- **自動ロール作成**: サーバーにロールが存在しない場合は自動作成
- **管理者限定**: パネル設置(`/setup_roles`)は管理者のみ実行可能

### スケジュール表示
- **`/setup_schedule` コマンド**: 現在と次回のスケジュールを手軽に閲覧できるボタン付きの**「常設スケジュールパネル」**を設置。（管理者用）
- **`/schedule` コマンド**: 従来通り、現在と次回のスケジュールをその場に表示。
- **自動クリーンアップ機能付き表示**: パネルのボタン（現在のスケジュール / 次回のスケジュール）を押すと、誰もが見られる形式で最新のスケジュールを表示します。その際、以前Botが送信した古いスケジュールメッセージは自動的に削除されるため、チャンネルがスケジュールで埋め尽くされることはありません。
- **日本語表示**: 武器名・ステージ名・ルール名を日本語で表示（splatoon3.ink ロケールAPI使用）

### 募集機能 (NEW!)
- **`/setup_recruit` コマンド**: 指定チャンネルに募集用のボタン付きパネルを設置。（管理者用）
- **@everyone 通知**: パネルの募集ボタンを押すと、即座に「@everyone 〇〇さんが募集を開始しました！🎮」といったメンションメッセージが指定チャンネルに送信されます。送信者の名前は、設定されていればサーバー内のニックネームが優先して表示されます。
- **自動再配置機能**: 募集ボタンが押されると、古い募集用パネルは自動的に削除され、常に最新の募集メッセージと一緒に一番下に新しいパネルを張り直します。ピン留めを探す手間が省け、ログもスッキリします。

### サポート機能 (NEW!)
- **`/setup_help` コマンド**: 使い方を説明するボタンを備えたヘルプパネルを指定チャンネルに設置。（管理者用）
- ボタンを押すと常に最新の使い方メッセージが表示され、過去の古い使い方メッセージは自動で整理されます。

### モンスターハンター：ワールド／アイスボーン
- **`/setup_mh_roles` コマンド**: 14武器種、下位／上位／マスターランク、Steam／PlayStation／Xbox、モンハン募集通知のロールパネルを設置します（管理者用）。既存のスプラトゥーン用ロールとは別のIDで管理します。
- **`/setup_mh_recruit` コマンド**: `モンハン募集`チャンネルを作成し、クエスト募集用の常設パネルを設置します。同名チャンネルがある場合は再利用します（管理者用）。
- 常設パネルの「クエストを募集する」は入力なしの簡易募集、「詳細募集」は対象、目的、募集人数、VC、開始時刻を入力する詳細募集です。どちらの募集後も新しいパネルが最下部へ再設置されます。
- **`/hunt` コマンド**: 対象モンスターまたはクエスト名、目的、募集人数（主催者を除く1〜3人）を指定して募集を投稿します。VCは未入力なら「なし」、開始時刻は未入力なら「今から」です。
- 募集メッセージの「参加する」「辞退する」「締め切る」ボタンで参加者と残り枠を更新します。重複参加や満員後の参加はできず、締め切れるのは募集主だけです。
- 同時に複数人が操作した場合は、更新後の参加者表示を確認してください。反映されていない場合は、もう一度操作してください（DBを使わないサーバーレス構成上の制約です）。
- 通知は `モンハン募集通知` ロールだけをメンションします。ロールが見つからない場合も募集自体は投稿され、通知なしであることをログに記録します。
- 既存の同名ロールを使う場合は、サーバー設定でそのロールの「メンション可能」を有効にしてください（Botは既存ロールの権限を変更しません）。

### スケジュール自動更新機能
- **1日1回の最新パネル自動更新 (Vercel Cron)**: 毎日 JST 1:01頃（※Hobbyプラン仕様）に、指定チャンネルの古いスケジュールメッセージをすべて削除し、最新の常設スケジュール確認パネルを再設置します。

## セットアップ手順

### 1. Discord Developer Portal での準備

1. [Discord Developer Portal](https://discord.com/developers/applications) でアプリケーションを作成
2. **Bot** タブで Bot を追加し、トークンをコピー
3. **General Information** タブから **Public Key** と **Application ID** をコピー
4. **OAuth2** → **URL Generator** で以下を選択:
   - **Scopes**: `bot`, `applications.commands`
   - **Bot Permissions**: `Manage Channels`, `Manage Roles`, `View Channels`, `Send Messages`, `Embed Links`, `Read Message History`, `Mention Everyone`, `Use Slash Commands`
5. 生成された URL でサーバーに Bot を招待

### 2. プロジェクトの準備とデプロイ

```bash
# リポジトリをクローン
git clone <このリポジトリのURL>
cd Discord-Bot

# 依存パッケージをインストール
npm install
```

#### Vercel へのデプロイ
本プロジェクトは Vercel にデプロイしてWebhookとして動かします。

1. [Vercel](https://vercel.com/) にログインし、GitHub等からこのリポジトリをインポートします。
2. デプロイ時の **Environment Variables (環境変数)** に以下を設定します:
   - `DISCORD_TOKEN`: Botのトークン
   - `CLIENT_ID`: アプリケーションID
   - `DISCORD_PUBLIC_KEY`: General InformationにあるPublic Key（署名検証に必須）
   - `SCHEDULE_CHANNEL_ID`: スケジュールパネルを定時送信したいチャンネルID
   - `CRON_SECRET`: Vercel Cron実行用の任意のシークレット文字列（例: `my_secret_cron_key`）
3. デプロイを実行し、発行されたドメイン（例: `https://your-bot.vercel.app`）をメモします。

### 3. Interactions Endpoint URL の設定

1. Discord Developer Portal の **General Information** に戻ります。
2. **Interactions Endpoint URL** に以下を入力して保存します。
   `https://[あなたのVercelドメイン]/api/interactions`
3. 保存が成功すれば、DiscordからBotへの疎通確認完了です。

### 4. スラッシュコマンドの登録

自分のPC上で1回だけコマンド登録スクリプトを実行します。
（`.env` ファイルを作成し、`DISCORD_TOKEN` と `CLIENT_ID` を記載しておいてください）

```bash
npm run register_commands
```

これで Discord サーバー上で `/setup_roles`、`/setup_mh_roles`、`/setup_mh_recruit`、`/setup_schedule`、`/hunt` などが使えるようになります。

### 既存サーバーでBotに権限を追加する

1. Discordのサーバー名を押し、**サーバー設定** → **ロール** を開きます。
2. Bot名と同じロールを選び、次の権限を有効にします。
   - `チャンネルの管理`: `モンハン募集`チャンネルの作成と権限設定に必要
   - `ロールの管理`: 武器種・ランク・通知ロールの作成と付け外しに必要
   - `チャンネルを見る`、`メッセージを送信`、`リンクを埋め込む`、`メッセージ履歴を読む`: 常設パネルの設置と更新に必要
   - `全員にメンション`: 簡易募集の `@everyone` 通知に必要
   - `アプリコマンドを使用`: セットアップコマンドの実行に必要
3. Botのロールを、Botが付与するモンハン用ロールより上へ移動します。Discordは自分より上のロールを操作できないためです。
4. 設定後、管理者が `/setup_mh_recruit` を実行します。権限が足りない場合はBotがエラーを返すため、上記を再確認してください。

## 使い方

- **ロールパネルの設置**:
  Bot を招待したサーバーのチャンネルで管理者が `/setup_roles` を実行します。パネルが設置され、ボタンからロールを取得できます。
  **注意**: Botのロール（役職）が、付与するロールより上の位置にある必要があります。サーバー設定からBotのロール位置を上に移動してください。

- **スケジュール確認パネルの設置 (NEW!)**:
  Botを招待したサーバーの任意のチャンネルで、管理者が `/setup_schedule` を実行します。スケジュール確認用のボタンが設置されます。メッセージを**ピン留め**しておくことをおすすめします。

- **毎日の最新パネル自動更新**:
  Vercel Cron により、1日1回（深夜1時頃）にチャンネル内の古いメッセージが削除され、最新のパネルが自動で再設置されます。

- **モンハンのロールパネル**:
  管理者が `/setup_mh_roles` を実行すると、カテゴリ別のパネルが設置されます。ボタンを押したメンバーにロールが付与され、もう一度押すと解除されます。Botのロールは付与対象ロールより上に配置してください。

- **モンハンのクエスト募集**:
  管理者が一度だけ `/setup_mh_recruit` を実行します。作成された `モンハン募集`チャンネルで「クエストを募集する」を押すと、入力なしで `@everyone ○○さんがモンハンのクエスト募集を開始しました！` と通知できます。対象・目的・人数・VC・開始時刻を指定したい場合は「詳細募集」を使います。詳細募集のメッセージは参加・辞退・締切ボタンで管理でき、どちらの募集後も新しい常設パネルが最下部へ再設置されます。簡易募集にはBotの「全員にメンション」権限が必要です。`/hunt` で直接詳細募集することもできます。

```
├── api/
│   ├── interactions.js     # Discord Webhook エンドポイント (Vercel Serverless Function)

│   ├── index.js            # スラッシュコマンド登録スクリプト
│   ├── roles.js            # ロール定義データ
│   ├── mh.js               # モンハン募集の状態・メッセージ生成

│   ├── panels.js           # パネル生成ロジック
│   ├── interactions.js     # ボタン処理ロジック
│   └── schedule.js         # スケジュール取得・Embed生成
├── vercel.json             # Vercel Cron の設定ファイル
├── package.json
└── README.md
```
